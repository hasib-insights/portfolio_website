# MD Hasib Hossain | Data Analyst Portfolio

A modern personal portfolio website built with HTML, Tailwind CSS, and JavaScript to showcase data analytics work, education, technical skills, and contact information.

## Live Demo

Visit the portfolio here:

- https://hasib-insights.github.io/portfolio_website/

## Overview

This repository contains a personal portfolio website for MD Hasib Hossain, a data analyst and BBA student focused on data-driven decision making, business analysis, and machine learning fundamentals.

The site is designed with a clean dark theme, smooth scrolling, animated UI elements, and sections for:

- Hero/introduction
- About me
- Academic background
- Skills and tools
- Featured projects
- Online profiles
- Contact form

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Iconify
- Google Fonts
- Formspree (for contact form submissions)

## Local Setup

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/hasib-insights/portfolio_website.git
```

2. Navigate to the project folder:

```bash
cd portfolio_website
```

3. Open `index.html` in your browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```
